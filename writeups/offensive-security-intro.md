Offensive Security Intro (TryHackMe)

Date: 8 Oct 2026 Platform: TryHackMe Difficulty: Beginner

What the room covered

An introductory room covering basic offensive security terminology and concepts: the tools and ideas used when testing systems for weaknesses, aimed at someone completely new to the field.

What I did

Worked through a short set of guided questions covering core terms and concepts used in offensive security, including the terminal (also called the shell or console), and the basic idea of how security testing is approached.

What I learned
The terminal (also called shell or console) is the main way security tools are controlled, usually through typed commands rather than clicking.
Offensive security has its own vocabulary, and getting comfortable with the terms early makes later, more technical rooms easier to follow.
This room was a good warm-up before hands-on labs like Meow, which put these ideas into practice.
What I'd do differently

Next time I'd take notes question by question as I go, rather than relying on memory afterwards, so the write-up can include more specific detail.
